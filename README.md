## How to Run

1. Open **Command Prompt (CMD)**.
2. Navigate to the folder containing `HelloWorld.html`.
3. Start a local Python HTTP server:

   ```bash
   python3 -m http.server 3901
   ```

   > Port `3901` is the port used for this project.

4. Open your browser and enter the following URL:

   ```text
   http://<ip-address>:3901/HelloWorld.html
   ```

   Replace `<ip-address>` with your computer's IP address.
